│  ✓ امسح الـ cache: Ctrl+Shift+R                    │
│                                                     │
│  ❓ لا يظهر زر لوحة الإدارة؟                       │
│                                                     │
│  → اذهب إلى: /test-permissions                     │
│  → تحقق من الدور: يجب أن يكون "مدير"              │
│  → امسح الـ cache وأعد تسجيل الدخول                │
│                                                     │
│  ❓ خطأ 403 عند /admin؟                            │
│                                                     │
│  → اذهب إلى: /test-permissions                     │
│  → تحقق من is_admin(): يجب أن يكون ✓              │
│  → إذا كان ✗، راجع الوثائق                        │
