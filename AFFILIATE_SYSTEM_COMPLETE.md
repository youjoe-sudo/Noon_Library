│                                                             │
│  ↓                                                          │

│  ↓                                                          │
│                                                             │

│      → total_earnings += commission_amount                  │
│      → pending_earnings -= commission_amount                │
│      → المسوق يرى الأرباح الإجمالية                        │
│                                                             │
│  ↓                                                          │
│                                                             │
│  12. المسوق يطلب سحب الأرباح                               │
│      → يتم إنشاء طلب سحب                                   │

│      → يتم التحويل                                          │
│                                                             │

## ⚙️ الدوال التلقائية

### 1. calculate_order_commission()
```sql
الوظيفة: حساب العمولة عند إنشاء أو تحديث الطلب

المدخلات:
- NEW.affiliate_id
- NEW.total_amount

العملية:
1. إذا كان affiliate_id موجود:
   a. الحصول على commission_rate من جدول affiliates
   b. حساب: commission_amount = total_amount × rate / 100
   c. حفظ rate و amount في الطلب
2. إذا لم يكن موجود:
   a. commission_rate = 0
   b. commission_amount = 0

المخرجات:
- NEW.commission_rate
- NEW.commission_amount
```

### 2. update_affiliate_earnings()
```sql
الوظيفة: تحديث أرباح المسوق عند تغيير حالة الطلب

السيناريوهات:

A. الطلب أصبح "confirmed":
   UPDATE affiliates
   SET pending_earnings = pending_earnings + commission_amount
   WHERE id = affiliate_id

B. الطلب أصبح "delivered":
   UPDATE affiliates
   SET 
     total_earnings = total_earnings + commission_amount,
     pending_earnings = pending_earnings - commission_amount
   WHERE id = affiliate_id

C. الطلب أصبح "cancelled":
   UPDATE affiliates
   SET pending_earnings = pending_earnings - commission_amount
   WHERE id = affiliate_id
```

## 🧪 سيناريوهات الاختبار

### السيناريو 1: طلب ناجح
```
الخطوات:
1. المسوق يشارك رابطه
2. العميل يزور الموقع
3. العميل يطلب كتاب بـ 500 ج.م
4. الإدارة تؤكد الطلب
5. الطلب يتم توصيله

النتيجة:
✅ pending_earnings: 0 ج.م
✅ total_earnings: 50 ج.م
✅ الطلب مرتبط بالمسوق
```

### السيناريو 2: طلب ملغي
```
الخطوات:
1. المسوق يشارك رابطه
2. العميل يزور الموقع
3. العميل يطلب كتاب بـ 500 ج.م
4. الإدارة تؤكد الطلب
5. الطلب يتم إلغاؤه

النتيجة:
✅ pending_earnings: 0 ج.م (تم الطرح)
✅ total_earnings: 0 ج.م
✅ لا توجد عمولة
```

### السيناريو 3: طلبات متعددة
```
الخطوات:
1. المسوق يشارك رابطه
2. 3 عملاء يزورون الموقع
3. كل عميل يطلب كتاب
   - العميل 1: 500 ج.م → delivered
   - العميل 2: 300 ج.م → confirmed
   - العميل 3: 200 ج.م → shipped

النتيجة:
✅ total_earnings: 50 ج.م (من العميل 1)
✅ pending_earnings: 50 ج.م (من العميل 2 + 3)
✅ إجمالي الطلبات: 3
```
